# المعايير الدولية (IFRS / IAS) — تطبيق مذاكرة

موقع عربي لشرح معايير IFRS وIAS، وفيه أمثلة وأخطاء شائعة واختبارات ومصطلحات.

- `index.html` + `data/` + `fonts/`: نسخة الويب، وتشتغل أوفلاين.
- `android/`: مشروع أندرويد يغلف نفس الموقع داخل تطبيق. التعليمات في `android/README.md`.
- `build.py`: بيحدّث قائمة السكربتات داخل `index.html` بعد إضافة ملفات جديدة في `data/`.

الشروح من تأليف شخصي، والنص الرسمي للمعايير متاح من IFRS.org.
