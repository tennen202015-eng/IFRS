# تطبيق المعايير الدولية (IFRS / IAS) — نسخة أندرويد

المشروع ده بيغلف نفس الموقع (index.html + data + fonts) داخل تطبيق أندرويد. كل الملفات جوه التطبيق، فالتطبيق بيشتغل أوفلاين.

## طريقة بناء الـ APK

1. نزّل **Android Studio** (مجاني) من developer.android.com وثبّته على الكمبيوتر.
2. افتح Android Studio واختار **Open**، وحدد مجلد `ifrs-android` كامل.
3. استنى لحد ما Gradle يخلص التحميل (أول مرة ممكن ياخد دقايق).
4. من القائمة: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. لما يخلص، هتظهر رسالة فيها زر **locate**، واللي هيفتح ملف `app-debug.apk`.
6. انقل الملف للموبايل وثبّته (لازم تفعّل "تثبيت من مصادر غير معروفة" مرة واحدة).

## لو عايز تغيّر اسم التطبيق أو الـ package

- اسم التطبيق في `app/src/main/res/values/strings.xml`.
- اسم الـ package (`com.example.ifrs`) في `app/build.gradle.kts` (applicationId و namespace) ولازم يتغير كمان في ملف `MainActivity.java` داخل مسار `java/com/example/ifrs`.

## تحديث المحتوى

كل مرة تعدّل المحتوى، انسخ `index.html` و`data` و`fonts` من مشروع الويب الأصلي إلى `app/src/main/assets/`، وبعدين ابني الـ APK تاني.

## ملاحظات

- النسخة دي للاستخدام الشخصي. لو هتوزعها على الناس، راجع شروط ترخيص IFRS الأول.
- الكود ده مكتوب بدون تجربة بناء فعلية على جهاز، لأن بيئة العمل اللي اتعمل فيها المشروع ما تقدرش تحمّل أدوات أندرويد. لو حصلت أي مشكلة في البناء، ابعت رسالة الخطأ وأنا أصلحها.
